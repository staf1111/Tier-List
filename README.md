Tier List – JavaFX

Application de bureau permettant de créer des tier lists de films et de jeux vidéo, réalisée en équipe de 4 dans le cadre de la SAÉ 2.01 du BUT Informatique (IUT de Laval).

Fonctionnalités
- Création de tier lists personnalisées
- Recherche de films et de jeux via les API REST **TMDB** et **RAWG**
- Placement des éléments par **drag & drop**
- Import d'éléments

Technologies
- Java, JavaFX (FXML, CSS)
- API REST : HttpClient
- JSON : Jackson
